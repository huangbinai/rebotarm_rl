# 002：Reach V2姿态观测

状态：已实施，2026-10-04。

## 决策

V1历史姿态观测未按wxyz正确计算相对旋转。直接修正会改变旧策略输入，因此保留V1，并新增RebotArm-Reach-Mjlab-V2。

V2采用世界系current * inverse(target)的最短旋转向量，单位rad；位置误差仍为current-target。仅改变姿态观测，不改变奖励、成功指标、物理时序、动作和PPO参数。

权重内嵌版本契约，加载前校验，并同时检查存在的旁置清单。V2拒绝无内嵌契约或V1权重，V1拒绝V2权重。禁止通过重写元数据转换旧策略；新任务从头训练。

项目源码关键边界和公式补充中文注释，维护的Markdown改为中文。任务ID、参数、文件名及机器可读字段保持稳定。
